# Mountains

[简体中文](README.md) | [English](README.en.md) | [한국어](README.ko.md) | [日本語](README.ja.md)

Mountains는 DeepSeek, GLM, Kimi처럼 캐시 사용에 별도 요금을 적용하는 모델을 위한 초기 단계의 코딩 에이전트입니다. 비용을 낮추고 빠르게 응답하며 실용적인 제어 기능을 제공하는 데 초점을 맞춥니다.

현재 제품은 단일 작업용 CLI와 TypeScript 엔진 패키지로 구성되어 있습니다. TUI와 데스크톱 애플리케이션은 개발 계획에 포함되어 있습니다. 이 저장소에는 공개된 정식 벤치마크 결과가 없으며, 비용이나 속도 면에서의 우위도 입증되지 않았습니다.

## 구현된 기능

- 프롬프트와 도구 정의의 앞부분을 일정하게 유지합니다. 가격을 고려해 오래된 도구 출력을 활성 컨텍스트에서 제거하는 기능은 선택 사항입니다.
- 선택적으로 컨텍스트를 복구할 수 있습니다. 보관된 출력을 다시 가져올 수 있고, 설정한 컨텍스트 창이 가득 차면 이전 상호작용 묶음을 프로그램이 생성한 실행 기록으로 대체할 수 있습니다.
- 파일 읽기, 검색, 편집, 쓰기 및 명령 실행을 지원하며, 승인 여부를 확인하고 변경 사항을 감지합니다.
- 고정된 승인 규칙을 적용합니다. 요청한 동작을 검토하는 독립된 모델을 선택적으로 사용할 수도 있습니다.
- 작업별 한도와 공유 지출 기록을 제공합니다. 선택적인 요청 예산 예약 기능은 주 모델과 승인 검토 모델의 사용 비용을 함께 반영합니다.
- 제공업체가 보고한 입력, 캐시, 출력 및 추론 사용량을 기록하고, 버전 정보가 포함된 로컬 비용 추정치를 제공합니다. 이 추정치는 제공업체의 청구서가 아닙니다.
- 로컬 실행 기록과 섀도 Git 체크포인트를 제공합니다. 현재 근거와 대조하는 프로젝트 메모리 기능은 선택 사항입니다.

대부분의 선택 기능은 기본 설정에서 꺼져 있습니다. 내장 승인 정책은 일반적인 파일 쓰기와 네트워크 명령을 허용합니다. 아래의 읽기 전용 예제부터 시작하고, 쓰기를 활성화하기 전에 [승인 안내](docs/approvals.md)를 읽어 보세요.

## CLI 설치 및 실행

`npm run check` 전체를 실행하려면 Node.js **22.19.0 이상**, npm, Git, ripgrep(`rg`), Python 3(`python3`), Bash가 `PATH`에 있어야 합니다. Python 기반 코드 검색을 사용하지 않는 CLI 작업에는 Python이 필요하지 않습니다. 명령 실행 작업에는 프로젝트별 도구가 추가로 필요할 수 있습니다. 이번 준비 과정에서는 Windows 네이티브 환경에서의 설치와 실행 동작을 검증하지 않았습니다.

저장소 루트에서 실행합니다.

```sh
npm ci
npm run check
npm run mountains
```

마지막 명령은 사용법을 출력한 뒤 종료 코드 `2`로 종료합니다. 이는 현재 CLI의 동작입니다. CLI는 `run`과 `replay`를 지원하며, `--help` 명령은 제공하지 않습니다.

셸이나 자격 증명 관리자를 통해 `DEEPSEEK_API_KEY`를 설정하고, `MOUNTAINS_BUDGET`에는 USD 기준의 양수 지출 한도를 설정하세요. 설정 파일에는 환경 변수 이름만 넣어야 합니다. 실제 `run` 실행은 작업 내용과 선택된 작업 공간 내용을 설정한 모델 서비스로 보내며, 비용이 발생할 수 있습니다.

임시 작업 공간에서 시작해 보세요.

```sh
npm run mountains -- run \
  --workspace ./examples/sample-workspace \
  --config ./examples/read-only.json \
  --task "Read the README and explain what this workspace contains. Do not change files."
```

이 예제는 고정된 승인 정책으로 쓰기와 네트워크 명령을 거부합니다. 명령 분류는 휴리스틱에 기반하며, 하위 프로세스는 샌드박스에서 실행되지 않습니다. 신뢰할 수 없는 프로젝트에는 격리된 환경을 사용하세요.

실행 결과는 기본적으로 `~/.mountains/runs/` 아래에 저장됩니다. 최종 요약, 실제 적용된 설정, 이벤트, 모델 기록 및 요청별 사용 내역이 포함됩니다. 이 파일에는 소스 코드와 작업 텍스트가 들어 있을 수 있으므로 공유하기 전에 내용을 검토하세요.

[설치](docs/installation.md), [설정](docs/configuration.md), [모델](docs/models.md), [승인](docs/approvals.md), [예산과 비용](docs/budgets-and-costs.md), [아키텍처](docs/architecture.md) 문서를 참고하세요. 사용자 문서는 주로 영어로 제공됩니다.

## 평가 방법 및 결과

계획된 평가는 SWE-bench Verified, SWE-bench Multilingual, SWE-bench Live에서 선정한 실제 수정 작업을 사용합니다. 정식 실행 전에 선정할 작업, 버전, 비공개 검사, 제외 기준 및 분석 규칙을 확정해야 합니다. 이 작업 모음을 사용한다고 해서 공식 SWE-bench 순위가 되거나 해당 모음의 저자들이 이 프로젝트를 보증하는 것은 아닙니다.

비교 대상으로 계획된 에이전트는 Mountains, OpenCode, Pi, DeepSeek Harness입니다. 각 비교에서는 모델 서비스, 작업의 시작 상태, 출력 허용량 및 최상위 작업 예산을 동일하게 유지합니다. 각 에이전트는 자체 도구, 프롬프트, 검색, 컨텍스트 축소 방식 및 자체 스케줄링을 유지합니다. 버전, 추론 설정, 기본값과 다른 설정, 플랫폼, 하드웨어 및 실행 경로를 공개할 예정입니다. 네이티브 경로와 호환 경로, Windows 네이티브 실행과 WSL 실행, 서로 다른 컨텍스트 창 조건은 각각 나누어 보고할 예정입니다.

정확성을 가장 먼저 봅니다. 해결한 작업 하나당 비용에는 실패한 시도, 재시도, 컨텍스트 처리, 하위 에이전트 호출 및 복구 호출이 포함됩니다. 전체 소요 시간에는 에이전트 시작, 모델 응답 대기, 도구 실행, 재시도 및 컨텍스트 처리가 포함됩니다. 설치와 외부 채점에 걸린 시간은 별도로 보고합니다. 여러 번 시도한 결과를 에이전트별 최상의 실행 결과 하나로 줄이지 않습니다. 불확실성 구간을 계산할 때도 같은 작업의 반복 시도를 한 그룹으로 유지합니다.

| 평가 | 작업 출처 | 정확성 | 해결한 작업 하나당 비용 | 전체 소요 시간 | 상태 |
| --- | --- | --- | --- | --- | --- |
| 정식 비교 평가 | Verified, Multilingual, Live에서 선정한 수정 작업 | 추후 기재 | 추후 기재 | 추후 기재 | 실행하지 않음 |
| 승인, 설치 및 장시간 작업의 사용성 | 실행 전에 등록할 고정 시나리오 | 추후 기재 | 추후 기재 | 추후 기재 | 실행하지 않음 |

**저자의 자체 테스트이며, 독립적인 검토를 받지 않았습니다.** 계획된 방법에 따른 정식 비교 결과는 아직 없습니다. 개발 과정의 검사는 새로운 작업, 다른 제공업체 또는 모든 운영체제에서의 성능을 입증하지 않습니다. 정식 작업 실행 도구와 그 결과 파일은 이 코드 스냅샷에 포함되어 있지 않습니다.

제공업체의 모델 별칭, 캐시 동작, 부하 및 사용량 보고 방식은 바뀔 수 있습니다. 온라인에서 다시 실행하면 패치, 토큰 수 또는 소요 시간이 달라질 수 있습니다. GLM과 Kimi의 어댑터 경로는 구현되어 있습니다. 다만 이번 오픈 소스 공개 준비 과정에서는 실제 제공업체 서비스에서의 검사와 보정을 거친 정확한 입력량 계산을 검증하지 않았습니다. 보고 요구 사항과 한계는 [평가 방법](docs/evaluation.md)을 참고하세요.

## 저장소 구조

```text
packages/       엔진, 컨텍스트, 도구, 제공업체, 프로토콜, 사용량 계산, 체크포인트
apps/cli/       단일 작업용 CLI
apps/tui/       계획된 터미널 인터페이스; 문서 자리 표시자
apps/desktop/   계획된 데스크톱 애플리케이션; 문서 자리 표시자
docs/           사용자 문서
examples/       간단한 설정 예제와 임시 샘플 작업 공간
```

## 개발 계획

- 사람이 승인하고 작업 요청을 명확히 할 수 있는 대화형 TUI를 만듭니다.
- 같은 엔진을 사용하는 데스크톱 애플리케이션을 만듭니다.
- 정식 평가 방법, 공개적으로 재현할 수 있도록 지원하는 자료 및 적용 범위를 명확히 밝힌 결과를 완성하고 공개합니다.
- 지원한다고 명시한 각 플랫폼에서 제공업체 연동과 설치를 검증합니다.

이는 계획이며, 현재 사용할 수 있는 애플리케이션 기능이나 출시 일정이 아닙니다.
