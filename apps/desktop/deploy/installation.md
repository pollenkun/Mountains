# Mountains Preview 2 安装后会保留聊天和设置

版本：0.2.0-preview.2。安装前先结束任务并退出 Mountains。
首次打开可以点击“跳过”暂不连接模型。软件会记住选择，之后可在模型按钮或设置中添加。

## Mac 下载 DMG 后，需要手动替换应用

1. Apple 芯片 Mac 下载 `Mountains-0.2.0-preview.2-mac-arm64.dmg`。
2. 打开 DMG，将 Mountains 拖入“应用程序”，确认替换。
3. 重新打开 Mountains，确认聊天记录和设置还在。

本版没有 Apple Developer ID 公证。首次打开可能需要到“系统设置 → 隐私与安全性”确认。完整处理说明见同目录 README。不要删除用户目录中的 `.mountains` 数据文件夹。

目前没有 Intel Mac 安装包。

## Windows 要按处理器选择安装包

- 常见 Intel、AMD 电脑使用 `Mountains-0.2.0-preview.2-win-x64.exe`。
- Windows ARM 电脑使用 `Mountains-0.2.0-preview.2-win-arm64.exe`。

不确定时，在“设置 → 系统 → 系统信息”查看系统类型。
运行安装包，沿用原来的安装位置。安装结束后打开应用，检查聊天记录。
Windows 包目前没有代码签名证书。系统可能显示来源确认提示；先核对下载地址和文件校验值。不要关闭系统安全保护来安装。

## 自动更新需要先手动安装支持更新的版本

本版在设置中提供“检查更新”和“自动下载更新”。自动下载可以关闭。
下载地址可选自动、CDN 或 GitHub。自动模式失败后会尝试另一个地址。
Windows 下载完可以“重启并更新”；Mac 下载完打开 DMG 后手动替换。
正在执行任务时，先等任务结束再安装。

旧版本若尚未内置更新功能，需要先手动安装本版，之后才能用应用里的更新入口。
