# Preview 2 已备齐安装包，公开发布仍需最后确认

版本统一为 `0.2.0-preview.2`。这批包包含 Mac ARM、Windows ARM 和 Windows x64。
更新说明在 `release-notes.md`，安装步骤在 `installation.md`。

## 测试地址与正式更新地址分开

本轮使用 `qa-20261103-r3` CDN 目录和 `desktop-update-qa-20261103-r3` GitHub 预览发布。
普通客户端不会读取这些测试地址。正式的 `desktop-preview` 与 `desktop-stable` 清单没有切换。
后续若重打包改变文件内容，应使用新的测试目录和标签；正式发布后的修订必须提升版本号。

## 发布前还要在 AMD 电脑上实际安装

Windows x64 包已生成，但打包成功不代表真机能正常使用。
需要确认首次安装、启动、聊天、计算机操作、升级和卸载。测试时保留原用户资料，不更改其他软件。

Mac 在独立测试资料上验证替换后重新打开，以及聊天和设置保留。
另一台 Mac 从浏览器下载后的首次打开与系统来源提示，仍需单独确认。

## 正式切换前先冻结这批文件

1. 将本批源码整理成可追溯的提交，保留原有改动。
2. 真机测试完成后，重新核对安装包和更新清单。
3. 获得发布确认后，先上传安装包，最后切换正式清单。
4. 再从普通客户端核对正式更新入口。

不要直接把测试地址写入客户端，也不要覆盖同名旧安装包。
