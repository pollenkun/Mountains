Mountains 0.2.0 Preview 2

- 支持检查更新，可选择自动下载。
- 更新可从 CDN 或 GitHub 下载，自动模式会在失败后尝试另一个地址。
- 更新包按段下载，中断时重试当前段。Windows 下载完成后可重启更新。
- Mac 下载 DMG 后，手动替换应用。
- 目标模式支持暂停、继续、修改和删除。暂停后当前工作继续，下一轮不再开始。
- 目标显示在输入框上方。
- 技能列表收起长说明，可展开查看。
- 调整设置、搜索和任务状态文案。
- Windows 桌面图标使用透明背景。
- 命令图标改为圆角方形。
- 首次连接模型引导可以跳过，重启后不再显示。

这是预览版本。Windows 安装时仍会显示安装向导。
Mac 尚未使用 Developer ID 公证，首次打开可能需要按系统提示确认。
没有更新功能的旧版本，需要先手动安装本版。
