# Mountains TUI

Status: in development; no terminal interface is implemented in this directory.

The planned TUI will use the shared engine and provide a conversational task interface, human approval, progress display, and clarification. Its interaction design and implementation are not yet available, and there is no delivery date.

For the current single-task command-line application, see [`apps/cli/`](../cli/) and the [installation guide](../../docs/installation.md).
