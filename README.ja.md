# Mountains

[简体中文](README.md) | [English](README.en.md) | [한국어](README.ko.md) | [日本語](README.ja.md)

Mountains は、DeepSeek、GLM、Kimi など、キャッシュ料金が設定されているモデル向けの、開発初期段階のコーディングエージェントです。低コスト、応答の速い実行、実用的な制御機能を重視しています。

現在の製品は、単一のタスクを実行する CLI と、TypeScript で書かれたエンジン用パッケージ群です。TUI とデスクトップアプリケーションは計画段階です。このリポジトリには、公開済みの正式なベンチマーク結果も、コストや速度の優位性を実証した結果もありません。

## 実装済みの機能

- プロンプトとツールの先頭部分を安定させ、料金を考慮して古いツール出力を使用中のコンテキストから取り除く任意機能。
- 任意のコンテキスト復元機能。保存してある出力を再取得でき、設定したウィンドウが埋まると、古いやり取りのまとまりをプログラムが生成した実行記録に置き換えられます。
- 承認チェックと変更検知を伴う、ファイルの読み取り、検索、編集、書き込み、コマンド実行。
- 静的な承認ルールと、要求された操作を審査する任意の独立したモデル。
- タスクごとの上限と、共有の支出記録。リクエスト分の予算を事前に確保する任意機能では、主モデルと承認用モデルを合わせて計上します。
- プロバイダーが報告する入力、キャッシュ、出力、推論の使用量と、バージョン管理されたローカルの費用見積もり。この見積もりはプロバイダーの請求書ではありません。
- ローカルの実行記録、シャドー Git によるチェックポイント、現在の証拠と照合する任意のプロジェクトメモリ。

任意機能の多くは、デフォルト設定では無効です。組み込みの承認ポリシーは、通常の書き込みとネットワークを使うコマンドを許可します。まずは以下の読み取り専用の例を試し、書き込みを有効にする前に[承認ガイド](docs/approvals.md)を読んでください。

## CLI のインストールと試用

`npm run check` を完全に実行するには、Node.js **22.19.0 以降**、npm、Git、ripgrep（`rg`）、Python 3（`python3`）、Bash が必要です。これらを `PATH` から実行できるようにしてください。Python を使うコード検索を利用しない CLI タスクでは、Python は任意です。コマンドを実行するタスクには、プロジェクト固有のツールが別途必要になる場合があります。今回の公開準備では、Windows ネイティブ環境でのインストールと実行時の動作は検証していません。

リポジトリのルートで実行します。

```sh
npm ci
npm run check
npm run mountains
```

最後のコマンドは使い方を表示し、終了コード `2` で終了します。これは既存の CLI の動作です。CLI は `run` と `replay` を受け付け、`--help` コマンドは提供していません。

シェルまたは認証情報マネージャーを通じて `DEEPSEEK_API_KEY` を設定し、`MOUNTAINS_BUDGET` に米ドル建ての正の支出上限を設定してください。設定ファイルには、環境変数の名前だけを記載してください。実際の `run` は、タスクと選択された作業領域の内容を設定済みのモデルサービスに送信し、料金が発生する場合があります。

使い捨ての作業領域から始めてください。

```sh
npm run mountains -- run \
  --workspace ./examples/sample-workspace \
  --config ./examples/read-only.json \
  --task "Read the README and explain what this workspace contains. Do not change files."
```

この例では、静的な承認ポリシーによって書き込みとネットワークを使うコマンドを拒否します。コマンドの分類はヒューリスティックに基づく推定であり、サブプロセスはサンドボックス化されていません。信頼できないプロジェクトには、隔離した環境を使用してください。

実行結果は、デフォルトで `~/.mountains/runs/` に保存されます。最終要約、実際に適用された設定、イベント、モデルの記録、リクエストの使用量と費用の記録が含まれます。これらのファイルにはソースコードやタスクの文章が含まれる場合があります。共有する前に内容を確認してください。

[インストール](docs/installation.md)、[設定](docs/configuration.md)、[モデル](docs/models.md)、[承認](docs/approvals.md)、[予算と費用](docs/budgets-and-costs.md)、[アーキテクチャ](docs/architecture.md)も参照してください。利用者向けドキュメントは主に英語です。

## 評価方法と結果

計画している評価では、SWE-bench Verified、SWE-bench Multilingual、SWE-bench Live から選んだ、実際の修正タスクを使用します。タスクの選び方、バージョン、非公開の検証項目、除外条件、分析ルールは、正式な実行前に確定させる必要があります。これらのタスクセットを使っても、公式の SWE-bench ランキングになるわけではなく、各タスクセットの作者による推奨を意味するものでもありません。

比較対象として予定しているのは、Mountains、OpenCode、Pi、DeepSeek Harness です。それぞれの比較では、モデルサービス、タスクの開始状態、出力の許容量、最上位タスクの予算を同じにします。各エージェントは、それぞれのツール、プロンプト、情報検索、コンテキスト削減、標準のスケジューリング方式を使用します。バージョン、推論設定、デフォルト以外の設定、プラットフォーム、ハードウェア、実行方式を開示します。ネイティブ方式と互換方式、Windows ネイティブ環境と WSL での実行、異なるコンテキストウィンドウ条件は、分けて報告します。

正しく解決できることを最優先にします。解決したタスク 1 件当たりの費用には、失敗した試行、再試行、コンテキスト処理、子エージェントへの呼び出し、復元のための呼び出しを含めます。開始から終了までの時間には、エージェントの起動、モデルの応答待ち、ツール、再試行、コンテキスト処理を含めます。インストールと外部の採点にかかる時間は、別に報告します。繰り返し実行した結果を、各エージェントの最良の実行だけに絞ることはしません。不確実性を示す区間の算出では、同じタスクに対する繰り返しの試行を同じグループとして扱います。

| 評価 | タスクの出典 | 正しさ | 解決したタスク 1 件当たりの費用 | 開始から終了までの時間 | 状態 |
| --- | --- | --- | --- | --- | --- |
| 正式な比較評価 | Verified、Multilingual、Live から選んだ修正タスク | 未測定 | 未測定 | 未測定 | 未実施 |
| 承認、インストール、長時間タスクの使いやすさ | 実行前に登録する固定シナリオ | 未測定 | 未測定 | 未測定 | 未実施 |

**作者による自己テストであり、第三者による独立した検証は受けていません。** 計画している方法に基づく正式な比較結果は、まだ得られていません。開発時のチェックは、新しいタスク、他のプロバイダー、すべての OS での性能を実証するものではありません。このコードスナップショットには、正式なタスク実行ツールとその結果ファイルは含まれていません。

プロバイダーのモデル別名、キャッシュの動作、負荷、使用量の報告方法は変わる場合があります。オンラインで再実行しても、同じパッチ、トークン数、所要時間になるとは限りません。GLM と Kimi のアダプター経由の処理は実装されていますが、今回のオープンソース公開準備では、実際のプロバイダーを使った検証や、校正済みの正確な入力トークン数の計測は確立されていません。報告に必要な事項と制約は、[評価方法](docs/evaluation.md)を参照してください。

## リポジトリの構成

```text
packages/       エンジン、コンテキスト、ツール、プロバイダー、プロトコル、使用量と費用の記録、チェックポイント
apps/cli/       単一タスクを実行する CLI
apps/tui/       計画段階のターミナルインターフェース。現時点では説明用の仮置き
apps/desktop/   計画段階のデスクトップアプリケーション。現時点では説明用の仮置き
docs/           利用者向けドキュメント
examples/       小さな設定例と、使い捨てのサンプル作業領域
```
